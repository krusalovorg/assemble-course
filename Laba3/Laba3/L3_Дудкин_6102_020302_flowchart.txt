```mermaid
flowchart TD
    C1_START((1))
    CALL_ASM["вызов calc(arr,n)"]
    C3_END((3))

    C3_START((3))
    OUT_ASM[/"вывод ASM result"/]
    CALL_CPP["вызов calcCpp(arr,n)"]
    OUT_CPP[/"вывод CPP result"/]
    FREE["delete[] arr"]
    PAUSE["system('pause')"]
    RET0["return 0"]
    E(["конец"])

    C2_START_ERR((2))
    TYPE_ERR{"invalid_argument ?"}
    CATCH_INV["catch invalid_argument"]
    CATCH_EX["catch exception"]
    OUT_ERR[/"вывод e.what()"/]
    PAUSE_ERR["system('pause')"]
    RET_ERR["return 0"]
    E_ERR(["конец"])

    C1_START --> CALL_ASM --> C3_END
    C3_START --> OUT_ASM --> CALL_CPP --> OUT_CPP --> FREE --> PAUSE --> RET0 --> E

    C2_START_ERR --> TYPE_ERR
    TYPE_ERR -- да --> CATCH_INV --> OUT_ERR --> PAUSE_ERR --> RET_ERR --> E_ERR
    TYPE_ERR -- нет --> CATCH_EX --> OUT_ERR
```

MERMAID (ГОСТ-стиль): часть 3 (подпрограмма calc, ASM)

```mermaid
flowchart TD
    S3(["начало calc(arr,n)"])
    INIT1["xor esi,esi; i=0"]
    INIT2["xor eax,eax; sum=0"]
    INIT3["mov ebx,arr; mov ecx,n"]
    N0{"ecx == 0 ?"}
    RET0["result = eax; return result"]

    LOOP["begin_loop"]
    ODD{"(esi & 1) != 0 ?"}
    ADD["add eax,[ebx + esi*4]"]
    NEXT["inc esi"]
    DEC["loop: ecx=ecx-1"]
    CONT{"ecx != 0 ?"}
    DONE["mov result,eax"]
    E3(["конец calc"])

    S3 --> INIT1 --> INIT2 --> INIT3 --> N0
    N0 -- да --> RET0 --> E3
    N0 -- нет --> LOOP --> ODD
    ODD -- да --> ADD --> NEXT --> DEC --> CONT
    ODD -- нет --> NEXT --> DEC --> CONT
    CONT -- да --> ODD
    CONT -- нет --> DONE
    DONE --> E3
```
