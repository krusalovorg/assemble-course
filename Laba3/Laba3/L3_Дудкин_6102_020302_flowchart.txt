MERMAID (ГОСТ-стиль): схема алгоритма на языке Ассемблера

```mermaid
%%{init: {
  "theme": "base",
  "themeVariables": {
    "fontFamily": "Times New Roman",
    "fontSize": "14px",
    "primaryColor": "#ffffff",
    "primaryTextColor": "#000000",
    "primaryBorderColor": "#000000",
    "lineColor": "#000000",
    "secondaryColor": "#ffffff",
    "tertiaryColor": "#ffffff",
    "background": "#ffffff"
  },
  "flowchart": {
    "curve": "basis",
    "nodeSpacing": 26,
    "rankSpacing": 32
  }
}}%%
flowchart TD
    S(["начало"])
    IN[/"n, arr"/]
    INIT1["xor esi, esi<br/>esi = 0"]
    INIT2["xor eax, eax<br/>eax = 0"]
    INIT3["mov ebx, arr<br/>mov ecx, n"]
    EMPTY{"ecx == 0"}
    C1((1))

    LOOP["begin_loop"]
    TEST["test esi, 1"]
    ODD{"(esi & 1) != 0"}
    ADD["add eax, [ebx + esi*4]"]
    SKIP["next"]
    INC["inc esi"]
    LOOPCMD["loop begin_loop<br/>ecx = ecx - 1"]
    CONT{"ecx != 0"}
    DONE["mov result, eax"]
    OUT[/"result"/]
    E(["конец"])

    S --> IN --> INIT1 --> INIT2 --> INIT3 --> EMPTY
    EMPTY -- да --> DONE
    EMPTY -- нет --> C1

    C1 --> LOOP --> TEST --> ODD
    ODD -- да --> ADD --> SKIP
    ODD -- нет --> SKIP
    SKIP --> INC --> LOOPCMD --> CONT
    CONT -- да --> C1
    CONT -- нет --> DONE --> OUT --> E
```
