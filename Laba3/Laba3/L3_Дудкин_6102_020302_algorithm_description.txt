3.3 Схема алгоритма

На рисунке 3.1 приведена схема алгоритма.

Алгоритм программы вычисления суммы элементов одномерного массива, имеющих нечетные индексы, можно разделить на три логических этапа. Первый этап — инициализация: ввод размера массива, ввод его элементов, установка начального значения суммы, равного 0, и установка начального индекса i = 1. Такой порядок необходим, так как суммирование выполняется только после получения всех исходных данных и подготовки начального значения результата.

Второй этап — циклический обход массива с шагом 2. На данном этапе обрабатываются только элементы arr[i], для которых индекс принимает значения 1, 3, 5 и далее до выполнения условия i < n. После добавления текущего элемента к сумме индекс увеличивается на 2, что исключает обработку элементов с четными индексами и сохраняет соответствие условию задачи.

Заключительный этап работы программы — сохранение полученной суммы в переменную result и вывод результата. В ассемблерной реализации начальный индекс хранится в регистре esi, сумма накапливается в регистре eax, адрес начала массива помещается в ebx, а счетчик оставшихся элементов хранится в ecx. Проверка нечетности индекса выполняется командой test esi, 1: если младший бит индекса равен 0, элемент пропускается, иначе значение arr[i] добавляется к общей сумме. По окончании цикла содержимое eax сохраняется в result.

Исходное выражение:
result = arr[1] + arr[3] + arr[5] + ... + arr[i], где i < n и i % 2 != 0
